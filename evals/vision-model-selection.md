# Pre-registration — FrameScribe vision-model selection

**Status:** pre-registered before any model was run (2026-10-07). Budget ceiling ~$33 total
(shared); this eval is expected to use a small fraction.

## Question

Which vision model should be the **primary** describer for FrameScribe (and which the
**fallback**), balancing description **quality** against **cost**?

## Candidates (owner-supplied)

| label | CLI id |
|---|---|
| Gemma 4 31B | `kilo/google/gemma-4-31b-it` |
| Gemini 3.8 Flash | `kilo/google/gemini-3.8-flash` |
| GLM 5.3 Flash | `kilo/z-ai/glm-5.3-flash` |
| Muse Spark 1.3 | `kilo/meta/muse-spark-1.3` |

## Fixtures

Six **deterministic synthetic** diagrams (`evals/figures/*.png`, generated by
`evals/make_figures.py`) with **exact** ground truth (`evals/ground-truth.json`): box
labels, directed connections, and one overlay each (highlight / circle / callout /
annotation). Synthetic fixtures are used so the ground truth is objective and the scoring
is not confounded by reference-description ambiguity.

## Procedure

Each model runs in its own Agent-Manager session, reads `evals/prompt.md` and the six
figures, and returns a JSON array (one contract object per figure). Results are landed in
`evals/results/<model>.json`.

## Metrics

- **Quality:** label recall, connection recall, overlay recall, and their mean.
- **Validity:** figures returning schema-conformant JSON (out of 6).
- **Cost / latency:** per-session tokens and cost via `kilo export`; wall-clock.

## Decision rule (pre-registered)

1. Any candidate returning **invalid JSON** for any figure is disqualified as primary.
2. Among the rest, the **primary** is the highest **quality-per-cost**: prefer the cheapest
   model whose mean recall is within **0.10** of the best (i.e. do not pay a large premium
   for a marginal gain).
3. The **fallback** is the best-quality model **from a different family** than the primary
   (reliability diversity), preferring lower cost on ties.
4. If all candidates fall below a mean recall of **0.60**, none is accepted and P-002 must
   reconsider the approach (not just the model).

## Limitations

- `k = 1` run per model (single sample) — no variance estimate.
- Synthetic fixtures are clean renderings; real talk figures (animation, compression) are
  harder. This selects a starting primary; a real-frame re-check is a later task.
- Cost is measured on these six images only; it scales with segment count in real use.
